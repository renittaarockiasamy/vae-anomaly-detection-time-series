# Variational Autoencoder (VAE) for Anomaly Detection

This project presents a Python implementation of a Variational Autoencoder (VAE) model for anomaly detection using unsupervised learning. The model learns normal data patterns and identifies anomalies based on reconstruction error.

## Features
- Encoder and Decoder neural networks
- Latent space representation
- Reconstruction and KL-divergence loss
- Model training and evaluation
- Jupyter Notebook implementation

## Technologies Used
- Python
- TensorFlow / PyTorch
- NumPy
- Matplotlib
- Scikit-learn

## How to Run
1. Install required libraries:

3. Run all cells sequentially.

## Results
The VAE successfully reconstructs normal samples and flags anomalies based on higher reconstruction error.
